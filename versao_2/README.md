# TSEA V-Twin · Versão 2

Esta pasta contém a versão focada no protótipo físico do TCC.

## Escopo

Esta versão demonstra, em escala reduzida, a lógica essencial da solução:

- uma bomba de vácuo;
- um sensor de pressão/vácuo;
- uma câmara/tanque de demonstração;
- uma lâmpada simulando a segunda bomba/Roots;
- cálculo de perda de carga na mangueira;
- pressão medida pelo sensor;
- pressão estimada no tanque;
- rampa de vácuo registrada automaticamente;
- logs, alarmes e rastreabilidade.

## Fora do escopo desta versão

- óleo real;
- múltiplos tanques reais;
- complexidade completa da linha industrial;
- Gêmeo Digital industrial completo.

A versão oficial completa da solução TSEA permanece na pasta versao_3.
