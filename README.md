# TSEA Sistema — Versões Organizadas

Este repositório mantém três versões do sistema em pastas separadas.

## Pastas

### versao_3
Versão mais recente do sistema, baseada no galho dev/front-redesign.

### versao_2
Versão anterior preservada antes da reorganização em pastas.

### sistema_prototipo_fisico
Cópia da versão 3 preparada para alterações futuras relacionadas ao protótipo físico.

## Como rodar uma versão

Entre na pasta da versão desejada.

Exemplo:

cd .\versao_3

Depois rode backend e frontend conforme a estrutura do sistema.
